# 自查与 AI 使用记录模板

现有文件头注明 AI 生成公共骨架或占位的事实，不代表成员已审核或签名。实现后逐文件补齐，不预填虚假“是”。

```java
/*
 * 文件：
 * 架构风格：
 * 本文件组件/连接器：
 * 架构约束自查（每项填是/否及说明）：
 * 1.
 * 2.
 * 3.
 * AI 工具及版本：
 * 用于任务：
 * 自行修改内容：
 * 声明人及任务书要求的手写签名：
 */
```

管道检查通信通道、直接调用、共享可变状态；黑板检查存储、知识源、控制器和知识源通信；调用/返回检查分层及迭代/回溯位置；Map-Reduce 检查三个阶段及真实按 key 分组。公共文件注明其基础设施职责。PowerShell/C# 使用对应注释语法。
